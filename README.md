# HECATE Connect Web

非官方的 HECATE G3M PRO 网页版驱动，用浏览器 WebHID 直接读写鼠标按键映射，不依赖桌面客户端。

- 在线使用：<https://nesror.github.io/hecate-connect-web/>
- 源码仓库：<https://github.com/nesror/hecate-connect-web>
- 当前界面版本：v1.3

> 这是一个个人逆向与互操作项目，与 HECATE 官方无关。仓库不包含官方驱动、官方图片或其他专有二进制文件。

## 功能

| 模块 | 网页端 | 写入鼠标 |
| --- | --- | --- |
| 6 键重映射（左键、右键、滚轮、前进、后退、DPI 键） | ✅ | ✅ 通过 WebHID |
| 7 档 DPI、XY 独立调节、DPI 指示灯 | ✅ | ❌ 仅保存在浏览器 |
| 回报率、直线/波纹修正、角度捕捉、按键延迟等 | ✅ | ❌ 仅保存在浏览器 |
| 灯效与亮度 | ✅ | ❌ 仅保存在浏览器 |
| 宏编辑（按键、鼠标动作、延迟、循环、停止方式） | ✅ | ❌ 仅保存在浏览器 |
| 多配置文件、JSON 导入/导出 | ✅ | — |

**写入范围仅限按键映射。** DPI、性能、灯光和宏目前不会写入鼠标固件，也不会伪装成已写入。将按键绑定到宏或协议未收录的功能时，写入会被整体拒绝，不会发送任何数据。

导入支持两种 JSON：

- 网页版导出的完整备份（全部页面设置与宏）。
- 官方 HECATE 驱动导出的配置文件（可转换按键、DPI、性能设置；宏数据不会导入）。

## 环境要求

- 桌面版 Chrome 或 Edge（Chromium 89+，需要 WebHID）。
- 安全上下文：HTTPS 或 `localhost` / `127.0.0.1`。
- 鼠标处于 2.4G 或有线模式，且官方驱动未占用设备。
- 不支持 Firefox、Safari 和移动浏览器。

WebHID 授权按源（origin）保存，每个站点首次连接都需要手动选择设备。

## 使用步骤

1. 打开在线地址，连接鼠标的 2.4G 接收器或 USB 数据线。
2. 点击右上角「连接鼠标」，在浏览器弹窗中选择 HID 设备。
3. 在「按键设定」中修改按键，点击写入并在确认框中确认。
4. 写入流程会：握手 → 进入配置模式 → 读取完整按键表 → 只修改 6 个按键槽位 → 提交 → 等待 500 ms → 重新读取校验。界面会显示逐槽位的校验结果。
5. 如果校验失败或提交失败，按提示重新插拔鼠标，再用「重新读取」确认设备状态。

首次使用建议先「导出配置」备份，再执行写入。

## 数据与隐私

- 所有配置保存在浏览器 `localStorage`（键名 `hecate-connect-web:state:v1`），没有后端、账号或遥测。
- 导入/导出都在本地完成，文件不会上传。
- WebHID 设备授权由浏览器管理，可在站点权限中撤销。

## 协议说明

协议来自对已安装官方驱动的逆向分析，用于与用户自己的鼠标互操作。网页端细节见 [`src/hid/protocol.ts`](src/hid/protocol.ts) 和 [`src/hid/HecateHid.ts`](src/hid/HecateHid.ts)。

- 设备：HECATE G3M PRO，`VID 0x320F` / `PID 0x706B`。
- HID：厂商集合 `UsagePage 0xFF1C` / `Usage 0x92`，输入输出报告 64 字节，报告 ID `4`。
- 帧格式：`[0]=0x04`、`[1..2]=校验和（字节 3..63 的 16 位小端累加）`、`[3]=命令`、`[4]=长度`、`[5..6]=偏移（小端）`、`[7]=状态`、`[8..63]=负载`。
- 握手 `0xAA` 返回状态 `0xFF` 表示就绪；读取命令需要携带对应长度的零填充请求。
- 主要命令：`0x01` 进入配置、`0x02` 提交并退出、`0x03` 读设备头、`0x07` 读按键表、`0x09` 写按键表。
- 按键表每项 3 字节大端：槽位 0 左键、1 滚轮、2 右键、3 前进、4 后退、5 DPI 键；`0xA00000` 表示禁用。
- DPI 键相关厂商码：`0x130100` DPI+、`0x130200` DPI−、`0x130300` DPI 循环。

写入前会重新读取设备头（校验 `AA 55` 标识与按键数量）和完整按键表，因此不会覆盖设备上的其他按键槽位。协议已在真机上通过原生 HID 工具验证；WebHID 链路仍需要更多浏览器与固件组合的实机确认。

## 已知限制

- 只有按键映射会同步到鼠标；其他页面是本地配置编辑器。
- 绑定宏、部分组合键或未收录功能时无法写入，界面会明确提示并中止。
- 官方驱动运行时可能独占设备，请先退出官方驱动。
- 设备固件差异可能导致协议不兼容；此时握手或读取设备头会失败，不会盲目写入。
- 页面更新后浏览器可能缓存旧资源，遇到行为不一致时用 `Ctrl+Shift+R` 强制刷新。

## 项目结构

```text
src/
  App.tsx              页面状态、配置文件与设备写入流程
  components/          侧边栏、顶栏、鼠标示意图、弹窗等
  pages/               按键、DPI、性能、灯光、宏页面
  hid/protocol.ts      帧格式、命令、按键表编解码
  hid/HecateHid.ts     握手、读取、写入、提交与校验
  hid/useHecateDevice.ts  WebHID 授权与连接状态
  profileIO.ts         导入、导出与官方 JSON 转换
  defaults.ts          默认配置与型号信息
  styles.css           全局样式
```
